# DCRO Android downloads

**[Get the latest DCRO APK](https://github.com/Kogollones/dcro-downloads/releases/latest)**

Open the latest release and select the `.apk` file under **Assets**. The source-code ZIP and TAR files are not the Android game.

**No GitHub account or sign-in is required.** This download repository is public; the separate client development repository is private.

For a one-click download of the verified v1.0.38 release: **[Download DCRO v1.0.38 APK](https://github.com/Kogollones/dcro-downloads/releases/download/v1.0.38/dcro-1.0.38.apk)**. This starts the APK download directly. Use the latest-release link above to check for newer versions.

This independent download mirror distributes the same signed APK as the game's official update service. Each release includes a `SHA256SUMS` file for checking that the download is complete and unchanged.

## Update an existing installation

Install the downloaded APK over your existing DCRO installation. Keep the game installed and preserve its data. The Android package and signing identity remain the same as the official client.

If Chrome is stuck at 100% on the primary site, cancel that stalled download and use the APK in the release linked above. A page saying **ERR_BLOCKED_BY_CLIENT** or **blocked by an extension** is a separate browser-extension block; this mirror provides another download route without requiring changes to your extensions or security settings.

If this mirror also fails, include your browser/version, phone model, download URL and the exact message when reporting the problem. Do not share account passwords or transfer codes.

## Release integrity

Only verified, already approved client releases belong here. The APK uploaded here must have the exact same file size, SHA-256 and Android signing certificate as the approved release. Local test builds and unsigned packages must not be published as official updates. Keep signing keys, account data and extracted game assets out of this repository.
